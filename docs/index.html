O que é

A nyxOS é uma UI library para criar janelas, abas e controles em scripts de Roblox. Tudo com visual de terminal: texto que se decodifica, chuva Matrix no fundo, notificações digitadas e uma bolinha no canto quando a janela é minimizada.

Recursos

  • Abas com ícones (emoji ou imagem), janela arrastável e minimizar para bolinha
  • Componentes: botões, toggles, sliders, dropdown, checklist, radio, caixa de texto, tecla de atalho, paleta de cores, tabela, gráfico de barrinhas, console, terminal e mais
  • Notificações com tipos: info, sucesso, aviso, erro e nyxOS
  • Configurações salvas automaticamente entre execuções
  • Animação de inicialização com opção de pular, e chuva Matrix que pode ser desligada
  • Erros dentro das funções aparecem como notificação, sem travar a interface

Como usar

Cole este código no seu executor:

local NyxOS = loadstring(game:HttpGet("https://raw.githubusercontent.com/btz157/nyxOS/main/dist/nyxOS-beta.lua"))()

local nyx = NyxOS.new({ Title = "Meu script", Size = Vector2.new(720, 440) })

local main = nyx:Tab("Início", "exemplo", "🏠")
main:Section("Ações")
main:Button("Olá", function()
	nyx:Notify("olá!", 3, "success")
end)

Perguntas frequentes

A nyxOS é gratuita? Sim. O código é público e pode ser usado em testes e scripts pessoais.

Funciona em qualquer executor? Depende do executor ter game:HttpGet e loadstring. Use o script de teste universal para checar.

Por que é beta? A lib ainda está em testes. Erros são corrigidos a cada versão.

nyxOS é um projeto independente, sem vínculo com a Roblox Corporation. Use com responsabilidade e de acordo com as regras de cada jogo e plataforma.
